#  Email / SMS Spam Classifier

A Machine Learning based web application that classifies messages as  
 **Spam** or  **Not Spam** using **NLP techniques**.

---

##  Features
- Text preprocessing (tokenization, stopwords removal, stemming)
- TF-IDF Vectorization
- Naive Bayes Classifier
- Streamlit-based interactive UI
- Real-time Spam / Not Spam prediction

---

##  Tech Stack
- Python
- Scikit-learn
- NLTK
- Streamlit
- Pandas, NumPy

---

##  How the Project Works
1. User enters Email or SMS text  
2. Text is cleaned and preprocessed  
3. TF-IDF converts text into numerical features  
4. ML model predicts Spam or Not Spam  
5. Result is shown on Streamlit UI
